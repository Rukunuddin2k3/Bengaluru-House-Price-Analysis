# Bengaluru House Price Analysis

## Tools Used
- Python
- Pandas
- NumPy
- SQL
- Power BI
- Matplotlib

## Project Overview
Analysis of Bengaluru house prices to identify factors affecting property prices.

## Key Insights
- Cubbon Road has the highest average price among the displayed locations.
- Average price generally increases with BHK.
- Super built-up Area represents the largest share of properties.
- Total Sqft and property price show a generally positive relationship.
